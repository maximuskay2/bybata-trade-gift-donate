# PayPal AI demo video

Record one continuous take under 3 minutes. Use the sandbox seller and buyer from `npm run seed:paypal-ai`. USD only. Gift and donate are not part of this video.

| Time | Shot |
| --- | --- |
| 0:00 | Home. Say the product: Bybata makes an uneven barter fair with a PayPal top-up. |
| 0:15 | Show the MacBook listing and the paperback offer side by side. |
| 0:35 | Open the offer and tap **Even this trade**. |
| 0:50 | Read the suggestion card: amount, plain-language reason, and confidence. If `OPENAI_API_KEY` is unset, say this estimate comes from category price bands. |
| 1:15 | Accept on the bidder phone. Switch to the owner and accept. Optional cut: counter once, then accept the new amount. |
| 1:40 | Bidder taps **Pay with PayPal** and approves the sandbox payment. |
| 2:05 | Back in the app, refresh. The card says **Paid with PayPal**. |
| 2:20 | Cancel the trade, or tap dispute. Show the card change to **Refunded**. |
| 2:40 | End on the offer. Say gift and donate stay free, and the top-up only applies to trade. |

Upload the file to YouTube and use that URL in the hackathon form. This repo does not store the video.
