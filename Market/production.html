3. Gamification Dynamics: The KARMA Engine System

KARMA transforms positive actions into verifiable trust tiers.

Total KARMA = Σ(Trades × 50) + Σ(Gifts × 30) + Σ(Donations × 40) + Σ(Community Posts × 10) + Verification Bonus (100) + Welcome Bonus (100)
[Tier 7: LEGEND] → Max visibility boosts + early feature access ▲ [Tier 6: DIAMOND] → Priority admin dispute resolution ▲ [Tier 5: PLATINUM] → Multi‑tier campaign structuring ▲ [Tier 4: GOLD] → Escrow verification bypass ▲ [Tier 3: SILVER] → Unlimited peer‑to‑peer chat threads ▲ [Tier 2: BRONZE] → Verified profile badge eligibility ▲ [Tier 1: NEWCOMER] → Base config (100 KARMA initial)

Behavioral Reward Loop: Action (swap/gift) → Variable reward (KARMA points) → Status unlock (higher visibility) → Investment (continued engagement).
